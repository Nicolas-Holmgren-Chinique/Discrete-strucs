The only files that matter for this project is the views.py and index.js this is where all the logic is,
most files dont really have anything that pertains to this project like models.py and manage.py for example


To run the code and be able to use all depencies, you must first make sure you have python on your device


if not make sure to install python 

then you will want to create a virtual environment, I dont think you will be able to use the one i have set Update

in the terminal, make sure you are in the correct folder, python -m venv .venv then to activate run .venv\Scripts\activate 
for a mac the commands are different

You want a venv so you dont install globaly all the depencies, once the venv is activated
you want to run pip install -r requirements.txt
this file has all the depencies and its versions, this way you will be able to run the code




Django code running

to run django code, open the terminal and run python manage.py runserver this will run a web server,
and in the terminal the local host 127.0.0.0 link should appear, http://127.0.0.1:8000/ this link  ctrl and click should open it into the browser


If all goes well the setup should work and you will be able to run the code and see the result
